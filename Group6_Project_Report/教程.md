# 🎓 第六组项目 · Windows 现场重跑 + 交作业 完整教程

> 适用：在 Windows 上从 git 拉代码，本地重跑全流程，最后改名打包交作业。
> 所有 `python xxx.py` 命令都必须在 **Source Code 文件夹**里运行，否则找不到 `Data`。

---

## 阶段 0：准备工作（装环境，只需做一次）

### 0-1 装 Python 3.8
- 去 python.org 下载 Python 3.8.x（Windows installer）。
- 安装时第一屏务必勾选 ☑ **"Add Python to PATH"**，然后点 Install。
- 验证：开始菜单搜 `cmd` 打开命令行，输入：
  ```bat
  python --version
  ```
  显示 `Python 3.8.x` 就对了。

### 0-2 装 Java（pyspark 模块2/3 需要）
- 下载 JDK 8 或 JDK 11（Adoptium / Oracle 都行）。
- 安装后设置环境变量 `JAVA_HOME`（指向 JDK 安装目录，如 `C:\Program Files\Java\jdk-11`）。
- 验证：新开一个 cmd，输入：
  ```bat
  java -version
  ```
  能显示版本号即可。
- 💡 只跑模块1（清洗）不需要 Java；模块2/3/4 需要。

### 0-3 装 Git（如果还没有）
- 下载 Git for Windows，一路默认安装。

## 阶段 4：按顺序跑 4 个模块

**一条跑完、看到「完成」字样，再跑下一条。顺序不能乱。**

```bat

```

## 🆘 常见报错
| 报错 | 原因 / 解决 |
|---|---|
| `'python' 不是内部或外部命令` | Python 没加进 PATH，重装勾选 "Add Python to PATH" |
| `JAVA_HOME is not set` / Java 相关 | 模块2/3 缺 Java，装 JDK 8/11 并配 `JAVA_HOME` |
| `No module named pandas/pyspark...` | 没装依赖，回阶段3 跑 `pip install -r requirements.txt` |
| 找不到 `Data` / json 0 个 | 没在 `Source Code` 文件夹里运行，先 cd 进去 |
| pyspark 报 `winutils` 错 | Windows 缺 winutils，建议改用老师的 Ubuntu 镜像跑 |
